# Which Dinner Lady Is The Witch?

One of the four dinner ladies is secretly a witch. Work out which one before
lunch is over.

Play it: https://milosarcade.com/dinner-lady-witch/

## How to play

- You get 5 peeks. Peek in a pocket, a pot, or at some shoes to find a clue.
- Witchy clues are purple.
- Normal dinner ladies can have one weird thing about them. The witch always has two.
- When you're sure, press Accuse!

Get it right and your streak goes up. Get it wrong and you're turned into a toad.

## Files

- `index.html` is the whole game: HTML, CSS and JavaScript in one file.

Your streak and scores are saved in the browser.
